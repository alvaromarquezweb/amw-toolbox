# Security Policy

## Supported Versions

Only the latest stable release is actively supported.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in AMW Toolbox, please report it privately rather than through a public GitHub Issue.

Please include:

- A description of the vulnerability.
- Steps to reproduce it.
- The affected version.
- Any relevant technical details.

Security reports will be reviewed and addressed as soon as reasonably possible.
